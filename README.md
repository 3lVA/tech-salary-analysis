# Tech Salary Analysis

## Overview
This project explores salary trends in the technology industry using Python. The analysis focuses on how experience level, remote work eligibility, and location influence salaries through data cleaning, exploratory data analysis (EDA), and data visualisation.

## Business Question
**How do salaries in the technology industry vary across key job factors such as experience level, remote work eligibility, and location?**

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Project Workflow
- Cleaned and merged multiple salary datasets into a master dataset.
- Filtered records to retain yearly salaries and technology-related roles.
- Handled missing values and removed unrealistic salary outliers.
- Performed exploratory data analysis (EDA) using Pandas.
- Created visualisations using Matplotlib to identify salary trends.
- Generated business insights based on the findings.

## Key Findings
- **Experience level** is the strongest predictor of salary, with median salaries increasing consistently across seniority levels.
- **Remote work eligibility** has minimal impact on median salaries despite fewer remote opportunities.
- **Location** significantly influences salaries, with major technology hubs offering higher median compensation.
